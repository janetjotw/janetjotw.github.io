On your terminal, start by running the following commands:

- Install Jupyter

```
`pip3 install jupyter`
```

2. Next, we have to open the Notebook Dashboard on the browser that is specifically designed for managing your Jupyter Notebooks. Imagine it being a launchpad for exploring, editing and creating your notebooks.

```
`jupyter notebook`
```

3. This brings up a Jupyter Notebook on your browser. The URL for the dashboard is something like `https://localhost:8888/tree`. The content is being rendered from your local machine. It populates the file system from your local directory.
