On your terminal, start by running the following commands:

1. Install Jupyter

  ```python
  pip3 install jupyter
  ```

2. Next, open the Notebook dashboard in your browser that is specifically designed for managing your Jupyter Notebooks. Imagine it being a launchpad for exploring, editing and creating your notebooks.

```
jupyter notebook
```

3. This brings up a Jupyter Notebook in your browser. The URL for the dashboard is something like `https://localhost:8888/tree`. The content is being rendered from your local machine. It populates the file system from your local directory.
